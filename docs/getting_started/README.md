# Getting started

初めて robotorchan を使う場合は、次の順に進めてください。

1. [Installation](installation.md) — Python と依存ライブラリを準備する。
2. [Quickstart](quickstart.md) — 最小の GP モデルを学習し、共通 API を確認する。
3. [Model selection](model_selection.md) — 入力・出力・タスク構造に応じてモデルを選ぶ。

より詳しいモデルの使い方は [モデル概要](../models.md) と [モデル別ガイド](../models/README.md)、獲得関数と候補生成は [Optimization](../optimization/README.md)、数理的背景は [Theory](../theory/README.md) を参照してください。

ドキュメント全体の案内は [Documentation](../README.md) に戻ってください。
