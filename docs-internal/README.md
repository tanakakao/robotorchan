# Engineering documentation

Publicly accessible engineering references for implementation and maintenance. This directory does not imply restricted access. Japanese learning material starts at [Documentation](../docs/README.md) and [Guide](../docs/guide/README.md).

- [Architecture](architecture/README.md): module ownership and extension boundaries.
- [Contracts](contracts/README.md): API, statistical and numerical requirements.
- [Verification](verification/README.md): test conditions, evidence and limitations.
- [Maintenance](maintenance/README.md): documentation, CI and authoring rules.

[Project records](../.github/project-records/README.md) preserve historical audits; they do not certify current behavior. Source and executable tests take precedence over historical inventories.
